Install KitchenSync App

Install KitchenSync directly onto your home screen or desktop dock so it opens full-screen without browser bars and syncs seamlessly across your devices.

🌌 Android (Samsung Internet)
  1. Tap the Download / Install icon in the address bar (or tap ≡ → Add page to → Home screen).
  2. Tap Install to create a full-screen WebAPK without a browser badge.
🤖 Android (Chrome / Edge)
  1. Tap the ⋮ menu in the top-right corner of Chrome.
  2. Tap Install app (not Create shortcut) for a clean icon with no browser badge.
💻 Desktop (Chrome / Edge)

Click the Install icon on the right side of your browser's address bar.
