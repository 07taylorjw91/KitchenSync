Install KitchenSync

Install KitchenSync on your home screen for full-screen shopping without browser bars and offline access.

Samsung Internet (Android)

Tap the Download / Install icon in the address bar, or tap ≡ → Add page to → Home screen → Install.

Chrome / Edge (Android & Desktop)

Open the browser menu (⋮) and choose Install app (not Create shortcut) for a clean, badge-free app icon.

iPhone & iPad (Safari)

Tap the Share button at the bottom of Safari and tap Add to Home Screen.
