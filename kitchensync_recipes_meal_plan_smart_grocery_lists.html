Household Sync & Firestore Model

KitchenSync separates private solo lists from real-time shared flatmate lists using dual Firestore collection paths, currently persisted locally in kitchensync_* keys:

● Personal Lists Path
users/{uid}/lists/{listId}

Private security rules: only readable and writable by your Firebase Auth UID.

● Shared Household Path
households/{id}/lists/{listId}

Real-time onSnapshot sync across all housemates in the household.
